# EPOS
[An Evolutionary Algorithm Assisted by an Ensemble of Pareto-Optimal Surrogate Models](https://ieeexplore.ieee.org/document/11589395)

- This is open-source code for EPOS implemented in MATLAB.

- All code is original and implemented to run on [PlatEMO](https://github.com/BIMK/PlatEMO/releases).

- A preprint of the "Accepted article" version is available at [arXiv](https://arxiv.org/abs/2608.01777).


## How to run

  1. Download all the files of EPOS and [PlatEMO](https://github.com/BIMK/PlatEMO/releases).
  
  1. Add the EPOS directory from this repository to the `Algorithms/Single-objective optimization` directory.

  1. Run `platemo.m` and select EPOS. See the documents of PlatEMO for more details.
